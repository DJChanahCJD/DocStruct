# 企业级 CRM 客户关系管理系统用户手册

## 1. 文档介绍
**适用对象**: 销售代表、销售经理、系统管理员
**版本**: 1.5.0
**最后更新**: 2023-11-15

## 2. 系统登录与主页

### 2.1 访问系统
请使用 Chrome 或 Firefox 浏览器访问 CRM 系统网址：`https://crm.example.com`。

### 2.2 登录账号
1. 在登录页面输入您的企业邮箱和密码。
2. 点击“登录”按钮。
3. 如果是首次登录，系统将强制要求您修改初始密码。

### 2.3 忘记密码
点击登录框下方的“忘记密码？”链接，输入注册邮箱，系统将发送重置链接至您的邮箱，请按照邮件指引完成密码重置。

## 3. 客户管理模块

### 3.1 新增客户 (Create Lead)
1. 点击左侧导航栏的“客户管理” -> “新增客户”。
2. 填写客户基本信息：
    - **客户名称** (必填): 完整的公司名称。
    - **联系人** (必填): 主要对接人的姓名。
    - **联系电话** (必填): 手机或座机。
    - **行业**: 选择客户所属行业。
    - **来源**: 选择线索来源（如展会、官网、转介绍）。
3. 点击“保存”按钮。

### 3.2 客户查重 (Duplicate Check)
在录入新客户前，建议使用顶部的搜索框输入客户名称或电话号码，检查系统中是否已存在该客户，避免重复录入导致的撞单。

### 3.3 客户分配 (Assignment)
销售经理可以在“公海池”中选中待分配的客户，点击“分配”按钮，选择指定的销售代表进行跟进。

## 4. 销售机会追踪 (Opportunities)

### 4.1 创建商机
对于有明确意向的客户，可以将其转化为商机：
1. 进入客户详情页。
2. 点击“新建商机”按钮。
3. 填写预计成交金额、预计成交日期及当前阶段（如初步接触、方案演示、商务谈判）。

### 4.2 推进销售阶段
随着跟进的深入，您需要及时更新商机阶段：
1. 在商机列表中找到对应商机。
2. 点击“编辑”或拖动商机卡片至下一阶段（看板视图）。
3. 系统会自动计算销售漏斗转化率。

### 4.3 赢单与输单
- **赢单**: 当客户签订合同时，将商机状态改为“赢单”，并上传合同附件。
- **输单**: 如果客户明确拒绝或选择了竞品，请将商机改为“输单”，并务必填写输单原因（如价格过高、功能不满足），以便后续分析。

## 5. 报表分析 (Analytics)

### 5.1 销售漏斗分析
点击“报表” -> “销售漏斗”，可以查看当前所有商机在各个阶段的分布情况，以及从线索到赢单的转化率。

### 5.2 业绩统计
销售经理可以查看团队成员的业绩排名，包括新增客户数、跟进次数、商机金额及回款金额。支持按周、月、季度筛选。

## 6. 常见问题排查 (Troubleshooting)

### Q1: 无法登录系统，提示“账号已锁定”
**问题描述**: 连续输入错误密码超过 5 次，账号会被临时锁定。
**解决方案**: 请等待 15 分钟后自动解锁，或者联系系统管理员手动解锁。

### Q2: 导出客户数据时出现乱码
**问题描述**: 导出的 CSV 文件在 Excel 中打开显示为乱码。
**解决方案**: 
1. 不要直接双击打开 CSV 文件。
2. 打开 Excel，选择“数据” -> “自文本/CSV”。
3. 在导入向导中，将“文件原始格式”设置为 **UTF-8**。
4. 点击“加载”。

### Q3: 页面加载缓慢或显示异常
**问题描述**: 点击菜单无反应或页面排版错乱。
**解决方案**: 
1. 尝试刷新页面 (F5)。
2. 清除浏览器缓存 (Ctrl+Shift+Delete)，选择清除“缓存的图片和文件”。
3. 检查网络连接是否正常。

### Q4: 收不到系统通知邮件
**问题描述**: 重置密码或审批通知邮件未收到。
**解决方案**: 
1. 检查垃圾邮件箱 (Spam)。
2. 确认个人设置中的邮箱地址是否正确。
3. 联系 IT 部门将 `noreply@crm.example.com` 添加到白名单。
