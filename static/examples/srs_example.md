# Software Requirements Specification (SRS) for Document System

## 1. Introduction
This document describes the functional requirement and non-functional requirements for the system.

## 2. Requirements
### 2.1 Functional Requirements
- The system shall allow users to upload PDF files.
- The system shall extract text from the uploaded files.

### 2.2 Acceptance Criteria
- User can see the upload button.
- User receives a success message after upload.
