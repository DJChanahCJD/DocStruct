## 2. 测试范围

本测试计划涵盖"易购"电商平台的核心功能模块，包括：

- 用户管理模块（注册、登录、个人信息管理）
- 商品管理模块（商品展示、搜索、分类）
- 订单管理模块（购物车、下单、订单状态流转）
- 支付模块（支付接口、退款处理）
- 后台管理模块（商品上架、订单处理、数据统计）

不包含范围：第三方物流系统对接、移动端 APP 专项测试。

## 5. 测试策略

### 5.1 功能测试策略

- **黑盒测试**: 基于需求文档设计测试用例，覆盖正常流程与异常流程
- **等价类划分**: 对输入数据进行有效/无效等价类划分
- **边界值分析**: 重点测试边界条件（如库存为0、价格为0.01等）
- **场景法**: 设计用户真实使用场景进行端到端测试

### 5.2 接口测试策略

- 覆盖所有 API 接口的正向与反向测试
- 验证参数校验（必填项、数据类型、长度限制）
- 验证鉴权机制（Token 有效性、权限控制）
- 验证异常处理（超时、服务降级、熔断场景）

### 5.3 性能测试策略

- **负载测试**: 逐步增加并发用户数，确定系统最大承载能力
- **压力测试**: 超过设计容量运行，验证系统稳定性与恢复能力
- **并发测试**: 模拟秒杀场景，验证库存扣减准确性
- **稳定性测试**: 7x24小时持续运行，检测内存泄漏等问题

### 5.4 兼容性测试策略

- 浏览器兼容性：覆盖主流浏览器最新两个版本
- 分辨率兼容性：1920x1080、1366x768、移动端适配
- 操作系统兼容性：Windows 10/11、macOS、iOS、Android

## 6. 测试交付物

1. **测试计划**（本文档）
2. **测试用例**: 覆盖全部功能点的详细测试用例集
3. **缺陷报告**: 包含缺陷描述、复现步骤、严重程度、修复状态
4. **功能测试报告**: 测试执行情况、通过率、遗留问题
5. **性能测试报告**: 响应时间、吞吐量、并发能力、资源占用
6. **测试总结报告**: 整体质量评估、风险评估、改进建议
7. **自动化测试脚本**: 核心业务流程的自动化测试代码
