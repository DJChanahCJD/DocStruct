## 测试用例 1: 用户注册功能

### 基本信息
- **用例ID**: TC-USER-001
- **用例标题**: 验证用户使用有效手机号成功注册
- **优先级**: P0

### 前置条件
1. 用户未注册过账号
2. 测试环境可正常访问
3. 短信验证码服务可用

### 测试步骤
1. 打开注册页面
2. 输入未注册的手机号（如：13800138001）
3. 点击"获取验证码"按钮
4. 等待接收短信验证码
5. 输入正确的6位验证码
6. 设置密码（8-20位，包含字母和数字）
7. 勾选用户协议
8. 点击"注册"按钮

### 预期结果
1. 页面成功跳转到注册成功提示页
2. 系统自动发送欢迎短信
3. 数据库中新增一条用户记录，状态为"已激活"
4. 用户可使用该手机号和密码正常登录

2. 显示订单号（格式：O20240120123456）

4. 库存相应扣减（预占库存）

## 测试用例 7: 密码错误锁定机制

### 基本信息
- **用例ID**: TC-USER-003
- **用例标题**: 验证连续输入错误密码后账号锁定
- **优先级**: P1

### 前置条件
1. 用户已注册且账号状态正常
2. 已知正确的手机号

### 测试步骤
1. 打开登录页面
2. 输入正确的手机号
3. 连续5次输入错误的密码
4. 第6次输入正确的密码

### 预期结果
1. 前5次提示"密码错误，还剩X次机会"
2. 第6次提示"账号已锁定，请15分钟后重试"
3. 账号状态变为"临时锁定"
4. 15分钟内无法通过正确密码登录
5. 15分钟后自动解锁，可用正确密码登录

## 测试用例 8: 库存不足场景

### 基本信息
- **用例ID**: TC-PROD-002
- **用例标题**: 验证商品库存不足时的处理
- **优先级**: P1

### 前置条件
1. 目标商品库存为 1

### 测试步骤
1. 用户A将该商品加入购物车（数量1）
2. 用户A提交订单（未支付）
3. 用户B尝试购买该商品

### 预期结果
1. 用户B进入商品详情页时显示"库存紧张"
2. 用户B尝试加入购物车时提示"库存不足"
3. 用户A取消订单后，库存释放
4. 库存释放后用户B可正常购买

## 测试用例 9: 优惠券使用功能

### 基本信息
- **用例ID**: TC-PROMO-001
- **用例标题**: 验证订单可使用符合条件的优惠券
- **优先级**: P1

### 前置条件
1. 用户持有有效的优惠券（满100减20）
2. 购物车商品总金额 >= 100元

### 测试步骤
1. 进入购物车，选择商品（金额120元）
2. 点击"去结算"
3. 在优惠券区域点击"选择优惠券"
4. 选择满100减20的优惠券
5. 查看订单金额变化
6. 提交订单

### 预期结果
1. 优惠券列表显示可用优惠券
2. 选择优惠券后，订单金额显示为 100元（120-20）
3. 优惠券状态变为"已使用"
4. 订单详情显示使用的优惠券信息

## 测试用例 10: 订单取消功能

### 基本信息
- **用例ID**: TC-ORDER-002
- **用例标题**: 验证用户可取消待支付订单
- **优先级**: P1

### 前置条件
1. 存在状态为"待支付"的订单

### 测试步骤
1. 进入"我的订单"页面
2. 找到待支付的订单
3. 点击"取消订单"按钮
4. 选择取消原因（"不想买了"）
5. 点击"确认取消"

### 预期结果
1. 弹出确认对话框
2. 取消成功后订单状态变为"已取消"
3. 预占的库存被释放
4. 使用的优惠券退回（状态变回"未使用"）
5. 订单列表显示该订单为已取消状态
