# BUG-1423 商品详情页加入购物车失败

## 基本信息

- 缺陷编号: BUG-1423
- 当前状态: Open
- 严重级别: High
- 优先级: P1
- 环境: Windows 11 + Chrome 123，测试环境 v2.4.1

## 问题摘要

登录用户在商品详情页点击“加入购物车”按钮后，页面没有成功加入购物车，控制台出现接口 500 错误。

## 复现步骤

1. 使用测试账号登录商城系统。
2. 打开商品 “机械键盘 K87” 的详情页。
3. 选择规格 “黑色 / 青轴”。
4. 点击 “加入购物车” 按钮。

## 期望结果

系统成功将商品加入购物车，并在页面右上角更新购物车数量。

## 实际结果

页面弹出“操作失败，请稍后重试”，购物车数量未变化。控制台显示 `/api/cart/add` 返回 500。

## 根因分析

后端在处理商品规格 ID 时没有兼容空库存快照，导致空对象取值报错。

## 临时绕过方案

在商品列表页直接加入购物车可以暂时避开该问题。

## 修复摘要

购物车服务已增加规格库存快照为空时的防御性判断，并补充接口异常日志。
