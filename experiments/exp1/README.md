# 实验一: 选最优模型

> 固定最终选择为 deepseek-v4-flash
> 论证：1. 国产最新模型，开源模型能力比较（引用一下榜单、Deepseek 官方文档等数据） 2. 适配国产华为芯片，应用前景更广  3. 性价比更高（打折，缓存命中）

模型对比: qwen-doc-turbo / deepseek-v4-flash / kimi-k2.5
> 价格对比详见[子目录](价格/README.md)

## 阶段一：
准备一个中等长度的 PDF 文档，分别用以上模型抽取 1 次，分别输出解析结果 JSON/MD 文件。

## 阶段二：
同时维护一份标准的抽取结果 JSON。
“每篇文档人工标 10 个关键对象 即可，不要全量标注。

例如 SRS 标：

5 个需求
2 个角色/实体
2 个接口
1 个流程

API 标：

5 个接口
3 个参数/返回项
2 个错误码或认证信息

然后统计：

抽对了多少
字段填完整了多少
有没有 source_ref/evidence”
然后比较不同模型的指标。

## 阶段三：评估指标

人工 + LLM 评审，各个维度5分制，最后取平均分。
- JSON 合法率
- 对象准确率
- 字段完整率
- 耗时
最高分的模型获胜
