## 实验设计

### 实验一：选最优配置

**目标：** 对比模型与 Prompt 效果

**数据：** 6个 文档（短3 / 中2 / 长1）

**变量：**

- 模型：qwen / deepseek / kimi
- Prompt：中英文、简短/详细

**评测：** 标准答案 + LLM评审

**指标：**

- 抽取准确率
- 字段完整率
- 耗时

------

### 实验二：验证类型泛化

**目标：** 验证最优配置对8类文档的覆盖能力

**数据：** 8类文档 × 各1（中等长度）

**变量：** 文档类型

**评测：** 标准答案 + LLM评审

**指标：**

- 抽取准确率
- 字段完整率

------

### 实验三：验证鲁棒性

**目标：** 验证系统在复杂场景下的稳定性与边界表现

**数据：** 12–16个文档（复用实验二 + 扩展样本）

**变量：**

- 格式：MD / Word / PDF / TXT
- 语言：中 / 英 / 混合
- 质量：标准 / 非标准
- 长度：短 / 中 / 长

（仅覆盖，不做全组合）

**评测：** 标准答案 + LLM评审

**指标：**

- 抽取准确率
- 字段完整率
